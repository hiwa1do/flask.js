# flask.js

This is a recreation of [flask](https://github.com/pallets/flask), written in a single JavaScript file made for Cloudflare Workers.

## Installation:
Download [/src/worker.js](https://github.com/hiwa1do/flask.js/blob/main/src/worker.js)

Go to Cloudflare Workers & Pages

Click "Create Application", "Start with Hello World!", then "Deploy"

Select all of the code in the box and replace it with the code from worker.js

Click deploy and your all done
